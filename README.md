## 📂 Project Overview
This repository hosts the **showcase landing page** (`index.html`) for the Cybersecurity UI Kit. The kit provides 12 production-ready "Smart Prefabs" optimized for whiteboard environments, featuring:

* **Cyber-Dark Aesthetic:** Built on a deep slate palette (`#020617`, `#1e1e1e`) with high-contrast neon accents.
* **High Fidelity:** Realistic data visualization, monospace typography, and nested grouping logic.
* **Technical Accuracy:** Components designed for specific security use cases (2FA, Firewall Logs, Topology).

## 📦 Asset Library
The kit includes the following 12 assets, categorized by function:

### 📊 Category A: Monitoring & Infrastructure
| Asset | Description |
|-------|-------------|
| **Server Health Card** | CPU/RAM usage gauges with live status indicators. |
| **Global Threat Map** | Radar-style geo-tracking visualization. |
| **Network Node** | Server stack icon with IP and connectivity status. |
| **Bandwidth Graph** | Line chart visualizing traffic spikes. |

### 🔐 Category B: Authentication & Access
| Asset | Description |
|-------|-------------|
| **Secure Login Modal** | Standardized dark-mode login interface. |
| **MFA Prompt** | 2-Factor Authentication modal with urgency timer. |
| **Biometric Scanner** | Face ID verification overlay. |
| **Privilege Toggle** | User management row with Admin/User switch. |

### 🛡️ Category C: Threat Management
| Asset | Description |
|-------|-------------|
| **Threat Alert** | High-contrast "Critical Error" banner. |
| **Firewall Rule** | Stackable row showing IP, Port, and Action. |
| **Terminal Console** | Unix-style command line window. |
| **Encryption Lock** | Visual confirmation of AES-256 security. |
